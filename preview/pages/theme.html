ThemeSwitcher

Palette selection is application chrome — the docs header owns it. The library ships the dx-theme-switcher surface; wire it to your palette driver (here: toggling <link> tags with disabled).

ThemeToggle

The dark-mode toggle reads and writes document.documentElement.dataset.theme — flip it in the header or here; both stay in sync.

Focus-visible rings on tonal controls use outline-* tokens. All border/outline tokens hold ≥ 3:1 vs bg/surface (WCAG 1.4.11).
