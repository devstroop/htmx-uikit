DataGrid

Sortable, pageable data grid with selection.

Client-side grid: sort (multi with data-dx-datagrid-multisort), per-column filter, pager, row selection (data-dx-datagrid-select="multiple" fires dx:grid-select), column picker, resize, drag-to-reorder, drag-to-group, inline edit/add/delete rows, frozen first column. Fires dx:grid-change (pageNumber, sorts, filters, filterString, oDataFilterString) — server round-trips via hx-get swap the data-dx-datagrid-rows region.
