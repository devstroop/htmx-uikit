AutoGrid

Responsive track grid (react AutoGrid parity): .dx-auto-grid fills the row with auto-fit tracks of at least --dx-auto-grid-min (default 240px); a lone track spans full width via min(100%, …). Track gap is the space.3 token; override per instance with an inline gap. Presentational only — no JS behavior.
